# 취향 번역기 — 화면 흐름 명세서

> 기준: 와이어프레임 최종안(탭 바 없음) 이미지 26장
> 플랫폼: 앱인토스(토스 미니앱)

---

## 1. 전체 화면 흐름

```
                 ┌──────────────────────────── 번역 흐름 ─────────────────────────────┐
                 │                                                                     │
 [01 첫 방문 홈] ─┴→ [02 음악 입력] → [03 분석] → [04 취향 프로필] → [05 분야별 번역 탭] → [06 추천 상세] → [07 반응] → [08 저장·공유]
                       ↕ 02-1 검색     ↘ 03-1 재시도    │                                                                  │
                                                        ├→ [10-0 궁합 초대 보내기] ··(링크)··> [10 초대 받기·친구] → 02 → … → [10-1 궁합 결과]
                                                        │
 [01-1 재방문 홈 (허브)] ←──────────────── '처음 화면으로' ────────────────────────────────────────────────────┘
      ├→ 새로운 취향 번역하기 → 02
      ├→ 지난 이슈 전체 보기 → [09 아카이브] → 09-1 취향 변화 / 09-2 기록 삭제 확인
      ├→ 친구와 궁합 → 10-0 (궁합이 도착했으면 → 10-1)
      └→ 하단 링크 → 11-1 서비스 소개 / 11-2 이용 약관 / 11-3 개인정보 처리방침
```

### 기본 원칙

1. **하단 탭 바가 없어요.** 재방문 홈(01-1)이 허브 역할을 해요. 모든 흐름은 홈에서 시작해서 홈으로 돌아와요.
2. **상단은 토스 내비게이션 바를 써요.** 뒤로가기(‹), 미니앱 이름·로고, ⋯ 메뉴, 닫기(×)가 있어요. 앱 안에 별도 헤더나 뒤로가기 버튼은 두지 않아요.
3. **앞으로 가기는 화면 하단의 메인 버튼, 뒤로 가기는 토스 뒤로가기**로 해요.
4. **로그인이 없어요.** 기기마다 만들어지는 익명 번호로 기록을 구분해요.
5. **문의·신고·일반 공유는 토스 ⋯ 메뉴의 공통 기능(고객센터)**을 써요.

## 2. 화면별 상세

> 모든 화면은 같은 구조예요. 상단에 영문 라벨, 굵은 한글 헤드라인, 보조 문장이 있고, 하단에 메인 버튼(민트색 둥근 버튼 + 오른쪽 화살표)이 있어요.
>
> **표기 규칙:** `{중괄호}`는 사용자의 음악·분석 결과에 따라 바뀌는 내용이에요. 와이어프레임에 들어간 곡명, 취향 이름, 추천 작품, 사진, 점수 등은 모두 **화면을 보여주기 위한 예시**예요. 따옴표나 백틱으로 적은 나머지 문구는 고정 문구예요.

### 01 첫 방문 홈

- **구성**
  - 라벨 `YOUR MUSIC, ANOTHER WORLD.`
  - 헤드라인 "좋아하는 음악을 다른 취향의 언어로."
  - 보조 문장 "플레이리스트에서 시작되는 나만의 작은 취향 잡지."
  - 콜라주 이미지(CD 플레이어, CD, 사진, 향수병) + 말풍선 "음악 너머의 나를 만나봐!" + 손글씨 "a little more like you ↗"
  - 메인 버튼
  - `MUSIC → TASTE → YOUR WORLD`, `MOVIE · BOOK · TRAVEL · PERFUME`
  - 안내 "좋아하는 3곡이면 충분해요. 약 1분 정도 걸려요."
  - 하단 정보 링크 3개
- **동작**

  | 요소 | 결과 |
  |---|---|
  | 메인 버튼 `내 취향 번역하기` | 02 음악 입력 |
  | `서비스 소개` · `이용 약관` · `개인정보 처리방침` | 11-1 · 11-2 · 11-3 |

### 01-1 재방문 홈 (허브)

- **구성** (위에서부터)
  1. 라벨 `WELCOME BACK.`, 헤드라인 "다시 펼친 당신의 취향 잡지.", 보조 문장
  2. `MY ISSUES` + `지난 이슈 전체 보기 →`
  3. 최근 이슈 카드: {무드 이미지 커버}, {날짜 · 이슈 번호}, {취향 이름}, {대표 곡 외 n곡}, {태그}, `다시 펼쳐보기`
  4. 점선 안내 박스 "친구와 취향 궁합을 볼까요? 링크 하나면 돼요." (친구가 분석을 마치면 "궁합이 도착했어요"로 바뀜)
  5. 메인 버튼 `새로운 취향 번역하기`
  6. 하단 정보 링크 3개
- **동작**

  | 요소 | 결과 |
  |---|---|
  | `지난 이슈 전체 보기` | 09 아카이브 |
  | 최근 이슈 카드 | 04 취향 프로필 (해당 이슈) |
  | 궁합 안내 박스 | 10-0 궁합 초대 보내기 (궁합이 도착했으면 10-1 궁합 결과) |
  | 메인 버튼 | 02 음악 입력 |
  | 하단 정보 링크 | 11-1 ~ 11-3 |

- 궁합 결과는 푸시 알림 없이 이 안내 박스로만 알려요.

### 02 음악 입력

- **구성**
  - 라벨 `TASTE SOURCE : MUSIC`
  - 헤드라인 "당신의 취향을 들려주세요."
  - 보조 문장 "요즘 가장 자주 듣는 음악 3–5곡. 유명한 곡보다, 당신다운 곡이면 좋아요."
  - 검색창 "곡 또는 아티스트를 검색하세요"
  - `MY TRACKS 3 / 5`
  - 선택한 곡 카드: 앨범 아트, 곡명, 아티스트, × 버튼
  - 점선 힌트 "반복해서 듣는 노래에 취향의 힌트가 있어요."
  - 메인 버튼
  - 안내 "3곡 선택 완료 · 조금 더 추가해도 좋아요"
- **규칙**
  - 최소 3곡, 최대 5곡까지 고를 수 있어요.
  - 같은 곡은 한 번만 담을 수 있어요.
  - 3곡 미만이면 메인 버튼이 흐리게 비활성화돼요.
- **동작**

  | 요소 | 결과 |
  |---|---|
  | 검색창 | 02-1 검색 상태 |
  | × | 곡 제거, 개수 갱신, 안내 "곡을 다시 추가하려면 검색창에 입력해주세요." |
  | 메인 버튼 `이 음악들로 번역하기` | 03 분석 |

- 고른 곡은 03에서 뒤로 오거나 03-1에서 다시 고를 때도 그대로 남아 있어요.

### 02-1 음악 검색 (상태)

- **구성**
  - 검색어가 입력된 검색창
  - 자동완성 결과: 썸네일, 곡명, 아티스트, `+ 담기` 또는 `담은 곡`
  - 아래에 현재 선택 목록(예: 2 / 5)
  - 경고 박스 "1곡만 더 고르면 번역할 수 있어요. (최소 3곡)"
  - 비활성화된 메인 버튼
  - 안내 "2곡 선택 · 같은 곡은 한 번만 담을 수 있어요"
- **동작**
  - 입력하는 대로 결과가 바뀌어요.
  - 이미 담은 곡은 `담은 곡`으로 표시되고 누를 수 없어요.
  - 5곡이 차면 더 담을 수 없고, 안내 "최대 5곡까지 선택할 수 있어요."가 떠요.
  - 결과가 없으면 "찾는 곡이 없어요. 아티스트 이름으로도 검색해 보세요."를 보여줘요.

### 03 분석 중

- **구성**
  - 라벨 `EDITING YOUR TASTE / 03`
  - 헤드라인 "음악 사이에 숨은 당신을 읽는 중."
  - 보조 문장 "멜로디에서 감각을 골라내고 있어요."
  - 일러스트 `MUSIC ↓ MOOD ↓ TASTE` + 키워드 스티커(dreamy, nostalgic, warm & quiet)
  - `TRANSLATING YOUR WORLD 03 / 04` 진행 바
  - 단계 4개: 01 음악의 분위기 듣기 / 02 감각 키워드 추출 / 03 나만의 취향 해석 / 04 다른 세계로 번역. 완료한 단계는 ✓, 진행 중인 단계는 •••
  - 메인 버튼 `내 취향 프로필 보기`
  - 안내 "거의 다 왔어요. 당신의 첫 번째 이슈를 만드는 중."
- **동작**
  - 단계가 끝날 때마다 진행 바와 체크가 바뀌어요.
  - 분석 중에는 메인 버튼 `내 취향 프로필 보기`가 비활성화돼요. 분석이 끝나면 버튼이 활성화되고, 눌러야 04 취향 프로필로 넘어가요. (자동 이동 없음)
  - 30초 안에 끝나지 않거나 실패하면 03-1 상태로 바뀌어요.

### 03-1 분석 재시도 (상태)

- **구성**
  - 라벨 `EDITING PAUSED / 03`
  - 헤드라인 "잠시, 번역이 멈췄어요."
  - 보조 문장 "음악을 읽는 데 평소보다 오래 걸리고 있어요."
  - 멈춘 일러스트(`· · ·`), 회색 진행 바
  - 실패한 단계에 빨간 글씨 "다시 시도 필요"
  - 안내 "고른 음악은 그대로 남아 있어요. 네트워크를 확인해 주세요."
- **동작**

  | 요소 | 결과 |
  |---|---|
  | 메인 버튼 `다시 번역하기` | 같은 곡으로 다시 분석 → 03 |
  | `음악 다시 고르기 →` | 02 음악 입력 |

### 04 취향 프로필

- **구성**
  - 라벨 `YOUR TASTE PROFILE` + `VOL. {이슈 번호}`
  - 헤드라인: {취향 이름} — 분석 결과로 생성 (예: "비 오는 밤의 아날로그 로맨티스트")
  - 해설 두 줄: {취향 해설} — 분석 결과로 생성 (예: "조용한 멜로디와 오래 남는 여운…")
  - 무드 이미지 띠: {취향에 어울리는 무드 이미지} + 고정 말풍선 `this is so you.`
  - 태그 4개: {취향 키워드} (첫 번째 민트 강조, 예: #nostalgic #quiet #cinematic #warm)
  - `THE SHAPE OF YOUR TASTE · 8 NOTES`: 감각 축 8개, 점 위치 = {축별 점수}
  - 보조 버튼 2개, 메인 버튼
- **8개 감각 축** (축 이름은 고정, 점 위치만 사용자마다 달라요. 왼쪽에 가까울수록 왼쪽 성향)

  | 왼쪽 | 오른쪽 |
  |---|---|
  | 고요한 | 에너지 있는 |
  | 아날로그 | 디지털 |
  | 몽환적인 | 선명한 |
  | 서정적인 | 추상적인 |
  | 따뜻한 | 차가운 |
  | 익숙한 | 새로운 |
  | 혼자만의 | 함께하는 |
